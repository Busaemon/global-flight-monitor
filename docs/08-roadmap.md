## 1. 今回の実装範囲

| 分野 | 用意した基盤 | 関連要件 |
| --- | --- | --- |
| 実データ | 初期ライブ、OpenSky、保存値と鮮度、明示的なデモ | FR-01 / 05 / 06 / 08 |
| 軽量化 | 集計 / ページ一覧 / 範囲地図 / 詳細、Canvas、地図遅延 import、サイズ予算 | FR-02 / 03 / 04 / 11、NF-01 |
| PWA | manifest、アイコン、画面だけのキャッシュ、オフライン案内 | FR-12 |
| 安全性 | HTTP ヘッダー、入力検証、プロキシ設定、API 制限、秘密の分離 | NF-04 / 05 / 06 |
| 保存 / 更新 | SQLite v2 移行、429 / 失敗期限の永続化、本番の背景更新 | FR-07 / 09 / 14 |
| 公開 | ビルド済み Node.js、Docker / Compose、Caddy HTTPS、永続 DB | FR-13 |
| 操作 | レスポンシブ、見えるフォーカス、ラベル、一覧から詳細、アクセシビリティ検証 | NF-02 / 03 |
| 継続開発 | CI、依存更新、Issue / PR、セキュリティ、資料更新 | FR-15 |

実装の用意と、利用者の実サーバーへ公開したことは分ける。テストの実行記録と未検証は [テスト仕様](07-test-specification.md) に記載する。

## 2. 本番公開までの残作業

| 順序 | 作業 | 完了条件 |
| --- | --- | --- |
| 1 | 公開先 / ドメイン / 規模を決める | DNS、永続領域、TLS、運営者、想定閲覧者を決定 |
| 2 | データ利用条件と認証 | OpenSky と地図の条件を確認。必要なら正式 OAuth を発行してサーバー設定 |
| 3 | HTTPS 公開 | 設定例を実値にし、API の直接公開を避け、証明書とヘッダーを確認 |
| 4 | 実端末と PWA | iPhone / Android、インストール、オフライン、更新、キーボード / 読み上げ、文字拡大 |
| 5 | バックアップ / 復元 | v2 DB と WAL を停止後保存、テスト用復元先で値と再起動を確認 |
| 6 | 負荷と長期運用 | 決めた規模で応答、容量、CPU、取得枠、監視、通知、再起動を確認 |
| 7 | リリース | 関連 PR、CI、公開前チェック、実行記録を確認して版を記録 |

未用意の OAuth 資格情報や公開先を、実装の段階で架空の値として埋めない。[公開前チェック](deployment-checklist.md) を用いる。

## 3. 将来案

| 候補 | 必要な前提 |
| --- | --- |
| さらに新しい観測 / 高い更新頻度 | 提供元の契約・利用枠・料金・商用許可と受信範囲 |
| 航空会社 / 機種 / 出発到着 | 信頼できる追加ソースと結合規則、ライセンス、欠損の表現 |
| お気に入り / 通知 | 個人情報、認証、保存、削除、通知の設計 |
| 過去の航跡 / 長期分析 | 機体ごとの履歴量、保存期間、利用条件、DB 設計 |
| 多台数の API | 共有 DB、取得ジョブ、共有レート制限、排他処理 |
| ストア向けネイティブアプリ | PWA では不足する要件、配布費用、権限と端末検証 |

これらは計画候補で現在の機能ではない。追加依存、契約、公開範囲が必要な変更は、具体的な要件と受入条件を定めてから進める。
