# 公開前チェック

現在は公開先と実 OpenSky OAuth クライアントが未定 / 未用意。実装とローカル検証の記録は [テスト仕様](07-test-specification.md) を参照する。この表は公開先で実施してチェックを入れる受入用で、チェックの空欄は実施済みを意味しない。

## 1. 公開先とデータ利用

- [ ] ドメイン、サーバー、永続ディスク、想定同時利用者、運営担当を決めた。
- [ ] OpenSky、OpenStreetMap のタイル利用ポリシー、追加サービスの利用条件を確認した。地図の帰属・Referer・通常のキャッシュを維持し、一括 / オフライン取得を実装していない。商用 / 再配布の許可を仮定していない。
- [ ] OAuth が必要なら正式クライアントを発行した。ID / secret はサーバーの秘密設定だけに置いた。
- [ ] 匿名 900 秒または契約に合う取得間隔にした。同じ IP のほかの利用と枠を確認した。
- [ ] DOMAIN / ACME_EMAIL / PUBLIC_ORIGIN を実際の値にした。example.com を公開設定に残していない。

## 2. ビルドと HTTPS

- [ ] 対象コミットの backend / build / audit / browser 検証が成功した。
- [ ] Docker build / Compose config を公開する環境で確認した。
- [ ] DNS A / AAAA、80 / 443、TLS 証明書と更新を確認した。
- [ ] API 3001 と SQLite を外部へ直接公開していない。アプリは非 root / 永続 volume で起動した。
- [ ] `TRUST_PROXY_HOPS` が実構成と一致し、転送ヘッダーで API 制限を回避できない。
- [ ] HTTPS の CSP / HSTS / MIME / referrer / permissions のヘッダーを確認した。
- [ ] PUBLIC_ORIGIN の誤設定による 403 がなく、不要な他オリジン要求を許可しない。

## 3. 実データと PWA

- [ ] 初期ライブ、実際の source / 観測時刻 / 取得時刻 / 次回予定を確認した。
- [ ] 機数は観測範囲の値で、地図サンプルの件数や推測の全世界総数とは区別した。
- [ ] 取得失敗、保存値の古い表示、初回未取得、429 の期限と再起動後の維持を確認した。
- [ ] 実 OAuth を使用する場合、正常取得、secret の非露出、トークン更新を確認した。
- [ ] iPhone / Android の HTTPS URL でホーム画面に追加し、起動できた。
- [ ] オフライン起動を確認し、API と外部タイルが Service Worker の Cache Storage にない。
- [ ] アプリ更新時に古いキャッシュが切り替わり、再読み込み後も操作できた。

## 4. 操作と性能

- [ ] 実スマートフォンで検索、並び替え、ページ、地図、詳細、戻る / 閉じる操作を確認した。
- [ ] 320 px 幅と文字拡大で主要操作に到達でき、不要な横はみ出しがない。
- [ ] キーボード、見えるフォーカス、読み上げ、ステータス通知、動きの軽減を確認した。
- [ ] 地図だけでしか確認できない必須情報がなく、一覧 / 詳細で代替できる。
- [ ] 初期 JS / 総 JS / CSS の予算を満たした。地図の遅延 import が保たれている。
- [ ] 決めた同時利用数と実端末で、応答、CPU / メモリー、通信量を測定した。予算通過を負荷試験の成功と混同しない。

## 5. 運用と GitHub

- [ ] SQLite v2 の永続保存、停止 / 再起動、背景更新、履歴を確認した。
- [ ] 停止後の DB / WAL / SHM バックアップと、別環境の復元を確認した。
- [ ] 監視、ログ保持、ディスク容量、通知先、更新 / 事故時の担当を決めた。
- [ ] main への取り込み条件、CI / Dependabot と private security reporting を実設定で確認した。
- [ ] .env / DB / secret / バックアップがコミットと Artifact にないことを確認した。
- [ ] 公開 URL、プライバシー、版 / コミット、確認結果、未解決項目を記録した。

未完了の項目を「公開済み」「実 OAuth 確認済み」「WCAG 完全適合」「負荷に対応済み」と表現しない。公開先の変更後も TLS、オリジン、取得枠、永続領域を再確認する。
