# 画面仕様書

## 1. 基本構成

日本語を主な言語とする単一のダッシュボード。全観測の集計、地図、検索一覧、選択機体の詳細、機数の履歴、データ状態を示す。PC では広い地図と情報を並べ、スマートフォンでは操作可能な幅で縦に配置する。

| 部分 | 表示 / 操作 |
| --- | --- |
| ヘッダー | SKYTRACE、通信 / 観測状態、ライブ / デモの切替、更新 |
| 集計 | 飛行中観測数、位置あり、登録国数、平均値。検索で全観測の件数を減らさない |
| 地図 | 表示範囲内の機体、表示数 / 対象数、ズームと選択、帰属表示 |
| 検索一覧 | コールサイン / ICAO24 / 登録国、並び順、標準 8 件、前 / 次ページ |
| 詳細 | 一機の識別子、登録国、位置、高度、速度、地上航跡、垂直速度、通信 / 位置時刻 |
| 履歴 | 保存された機数の推移。観測時刻と直近最大 360 点 |
| データ説明 | OpenSky の観測範囲、更新予定、欠損、実データとデモの区別 |
| PWA 案内 | 対応環境でインストール、オフライン時の通信状態 |

## 2. 起動とモード

初期表示は `live`。明示的な選択または URL の `?mode=demo` で合成データを表示する。外部 API 失敗や接続切断でデモへ自動切替しない。モード切替時に前のモードの遅延応答や機体詳細が混入しないよう要求を管理する。

| 状態 | 表示の意味 |
| --- | --- |
| `live` | 観測が鮮度の基準内の実データ |
| `stale` | 最終保存した実データ。現在値であるとは案内しない |
| `unavailable` | 実データを正常取得していない。機数を `—` などの不明表示にする |
| `demo` | 明示的な合成データ。実測とは案内しない |
| 読み込み | 取得中を表示し、同じモードの保存済み観測があれば状態を伴って表示 |
| オフライン | 通信断を案内。保存された API を Service Worker から実測として復元しない |

観測時刻、取得時刻、次回外部更新の予定を区別する。観測から 120 秒超で古い状態にし、次の通信が応答待ちでも時計に応じて更新する。更新ボタンはサーバーの外部取得期限を解除しない。画面の UTC 時計は 1 秒、観測の鮮度確認は 5 秒の間隔で行い、時計だけの更新で地図を再描画しない。

## 3. 地図

地図は遅延読み込みする。機体は Canvas に描画し、すべての機体を DOM マーカーにしない。地図の表示範囲が変わると範囲 API を呼ぶ。スマートフォン 200 機 / PC 600 機が標準、API は最大 1,000 機。対象が多いときは deterministic なサンプルを返し、画面にサンプルの数であることを示す。

選択機体が検索と範囲の条件に含まれる場合はサンプルに残す。位置欠損の機体は一覧・集計に残り、地図には出ない。日付変更線をまたぐ範囲を扱う。検索は一覧と地図を絞るが、全観測の集計は変えない。

外部 CARTO タイルに接続できない場合は Natural Earth の簡易陸地を使い、地図の詳細が取得できないことを案内する。地図の著作権 / 帰属は常に残す。地図上で選べない利用者も検索一覧から機体詳細に到達できる。

## 4. 検索と一覧

| 操作 | 結果 |
| --- | --- |
| callsign / ICAO24 / 登録国を入力 | サーバーで大文字小文字を区別しない部分一致。最大 80 文字 |
| 並び順を選ぶ | callsign は昇順、高度 / 速度は降順、NULL は最後。同値は ICAO24 で安定 |
| 前 / 次ページ | ページ単位で API を取得。全機体をブラウザーへ読み込まない |
| 検索 / 並び順 / モードを変える | 先頭ページへ戻し、条件に対応する結果を表示 |
| 該当なし | 0 件を案内し、検索を変更またはクリアできる |
| 機体を選ぶ | 一機の詳細 API を取得し、選択状態と詳細を表示 |

入力は 250 ms の待機で連続入力をまとめる。非表示タブ / オフラインは定期取得を止め、表示または接続が戻ると再確認する。応答は mode / 検索 / ページの正確な URL に対応するメモリーキャッシュを最大 30 件に制限し、ETag を再検証する。要求は 10 秒でタイムアウトし、古い要求を取消して別の条件へ混入させない。

コールサイン欠損は ICAO24 を識別に利用する。登録国不明は不明とする。API の入力エラーや通信失敗を「検索結果 0 件」と混同しない。

## 5. 詳細と単位

| 項目 | 単位 / 意味 |
| --- | --- |
| ICAO24 | 6 桁の 16 進機体識別子 |
| コールサイン | 送信された値。空港・路線との対応は未取得 |
| 登録国 | 機体の登録に関する国。現在地の国とは異なる |
| 高度 | m。幾何高度を優先し、欠損時は気圧高度 |
| 対地速度 | km/h。API の m/s に 3.6 を掛ける |
| 地上航跡 | °。真北からの対地進行方向であり、機首方位とは限らない |
| 垂直速度 | m/s。正が上昇、負が下降 |
| 位置 | 緯度 / 経度。欠損は未取得 |
| 時刻 | 観測・取得・最終通信・位置更新を区別 |

測定値 NULL は `—` などで示す。機種、航空会社、出発 / 到着、旅客数を推測して表示しない。

## 6. アクセシビリティと読みやすさ

メインへのスキップリンク、名前のある領域、入力ラベル、操作の名前、選択状態とステータスの意味を用意する。一覧から選ぶと詳細の見出しへフォーカスを移し、閉じる / Escape で選択元へ戻す。フォーカスを見える状態にし、主要操作をキーボードで行えるようにする。スクリーンリーダーへ更新状態を伝える際は、毎秒の時計更新を過剰に読み上げさせない。本文と操作のコントラスト、タップ可能な余白、文字拡大を確認する。

スマートフォンの一覧は高度 / 速度を中心に表示し、登録国は識別子の近くへ、その他は詳細へ配置する。主要操作のタップ領域は 44 px を基準にする。

地図とグラフは一覧・数値・時刻でも内容を確認できる。`prefers-reduced-motion` に配慮し、色だけを唯一の状態表現にしない。目標は WCAG 2.2 AA。自動の axe 検査とキーボード確認に加え、公開前に実端末・読み上げを確認する。
