# 画面仕様書

## 1. 対象画面と参照先

初版は一つのダッシュボード画面で、集計、地図、機体詳細、履歴、検索一覧を利用する。
「ライブマップ」「フライト一覧」は同じページ内の移動リンクであり、別画面への遷移ではない。
本書は `src/App.tsx` と `src/styles.css` の現在の動作を基準にする。
API の項目は[API 仕様](06-api-specification.md)、集計条件は[要件定義](02-requirements.md)を参照する。

## 2. 画面の構成

| 順序 | 領域 | 内容・目的 |
| --- | --- | --- |
| 1 | ヘッダー | SKYTRACE、ページ内ナビゲーション、UTC 時計、OpenSky リンク |
| 2 | 見出し・モード | 画面タイトル、ライブ／デモ選択、接続状態 |
| 3 | 状態バナー | デモ、最終取得データ、取得不可の説明と操作 |
| 4 | 観測統計 | 飛行中機数、位置あり機数、登録国数、平均高度 |
| 5 | 地図 | 世界地図、航空機、拡大縮小、表示件数、凡例 |
| 6 | フライト詳細 | 選択した機体の情報、選択解除、位置確認 |
| 7 | 地図下の情報 | 観測時刻、取得時刻、次回取得までの秒数、間引き説明 |
| 8 | 履歴・データ範囲 | 飛行中機数の推移、受信範囲と情報源の説明 |
| 9 | フライト一覧 | 検索、並び順、一覧、ページ切替 |
| 10 | フッター | 名称と観測データの情報源 |

PC では地図と詳細を横に配置する。
幅 900 px 以下では詳細を地図の下へ配置し、選択時は詳細欄が見える位置へスクロールする。
幅 620 px 以下では統計を 2 列、履歴と説明を縦に配置する。

## 3. 初期表示と更新

初期モードはライブである。前回の選択を `localStorage` に保存できている場合はそのモードを使用する。
読込開始時の検索語は空、並び順は「便名順」、一覧は先頭ページである。
初期状態では機体を選択せず、詳細欄に地図または一覧から選ぶ案内を表示する。

画面は選択したモードの `/api/dashboard` を取得する。
初回応答がない間は「接続中」と地図の読込表示を出し、取得前の機数は「—」とする。
成功後は API の状態とデータを反映し、時刻と受信からの経過を 1 秒ごとに更新する。
時計が進むことは、機体位置の観測が毎秒更新されたことを意味しない。

| 更新項目 | 現在の動作 |
| --- | --- |
| ライブ状態の確認 | 標準設定では応答後 30 秒で次の API 取得 |
| 取得間隔を変更した場合 | API の間隔を 5～30 秒の範囲に収めて画面の次回確認に利用 |
| デモ状態の確認 | 応答後 10 秒で次の API 取得 |
| 画面から API への通信期限 | 1 回 10 秒 |
| ライブ通信失敗後の再試行 | 60 秒後 |
| デモ通信失敗後の再試行 | 10 秒後 |
| データを更新 | すぐにローカル API を問い合わせる。上流の期限はサーバーが管理 |

「データを更新」は通信中に無効化する。
保存済みデータがある状態で再取得すると、前のデータを表示しながら取得を行う。

## 4. 状態とバナー

| 条件 | 状態表示 | データ・操作 |
| --- | --- | --- |
| 初回の読込中 | 接続中 | 地図の接続案内。確定した統計を表示しない |
| 新しい実観測を取得 | ライブ受信中 | 実データの統計、地図、一覧、詳細 |
| 実観測から 120 秒超 | 最終取得データ | 観測時刻付きバナーと保持データ |
| 取得失敗、同じモードのデータあり | 最終取得データ | 保持データ、通信エラー、再取得 |
| 実観測の取得失敗、保持データなし | 受信できません | 「—」の機数、再取得、デモを体験 |
| 明示的なデモ選択で取得成功 | デモデータ | サンプルの説明バナーとデモの統計・履歴 |

ブラウザーでも観測時刻を確認し、120 秒を超えたライブ観測を古いデータとして扱う。
次の API 応答が保留されていても、古い観測を「ライブ受信中」のままにしない。
デモの通信が失敗して保持データを表示するときは、最終取得データの表示とデモバナーを両方残す。

`LIVE MAP` はライブモードの地図領域の名称である。
実際の鮮度は接続状態、バナー、観測時刻から判断する。
エラーによるデモへの自動切替は行わない。

## 5. 統計の表示

| カード | 元データ | 注意点 |
| --- | --- | --- |
| 観測中の航空機 | `stats.airborne` | 受信情報が有効な飛行中機体数 |
| 位置を取得した機体 | `stats.withPosition` | 地図用の有効な位置がある機体数 |
| 機体の登録国（推定） | `stats.countries` | 飛行中機体の登録国の種類数。Unknown は除外 |
| 平均高度 | `stats.avgAltitudeMeters` | 高度が取得できた飛行中機体の平均、m 表示 |

値は日本語の数値書式で表示する。
取得不可や未取得の統計は「—」とし、外部 API が 0 件を観測した場合の 0 と区別する。
検索、並び順、ページ、地図の間引きによって統計の母集団を変更しない。
平均速度は API に含まれるが、初版の統計カードには表示しない。

## 6. 世界地図の操作

地図はドラッグで移動し、＋／−で拡大縮小する。スクロールホイールによる拡大は無効である。
航空機の向きは地上航跡を使用し、欠損時は 0 度の向きで描画する。
マーカーを押すと詳細欄がその機体に変わり、選択マーカーを強調する。
機体選択だけでは地図の表示範囲を自動変更しない。
詳細の「地図で位置を確認」を押すと、その機体の位置へ移動して拡大する。

検索語の条件は地図にも適用する。
位置を持つ検索結果が 1,200 機を超えた場合は間引き、最大表示件数の説明を出す。
選択機体が現在の検索結果内にあり、有効な位置がある場合は、間引き後もそのマーカーを含める。
検索結果外になった選択機体は、選択が保持されていても地図に追加しない。

位置がない機体は一覧から選べるが、地図に描画しない。
検索結果が 0 件の場合は「一致する機体がありません」を表示する。
検索結果が位置なし機体のみの場合は、地図の表示件数が 0 機になる。
タイル取得に失敗した場合は簡易地図の案内を表示し、同梱の陸地背景を使う。
OpenStreetMap、CARTO、Natural Earth の帰属は地図に残す。

## 7. フライト詳細

| 項目 | 表示 | 欠損時 |
| --- | --- | --- |
| 表示名 | callsign、または大文字 ICAO24 | ICAO24 を表示 |
| ICAO24 | 大文字の 6 桁 | API で有効な識別子だけを扱う |
| 登録国 | `originCountry` | Unknown |
| 状態 | 飛行中／地上 | 現在の API の対象は飛行中 |
| 高度 | 四捨五入した m | — |
| 対地速度 | m/s を 3.6 倍し四捨五入した km/h | — |
| 地上航跡 | 真北から時計回りの角度、四捨五入した ° | — |
| 垂直速度 | 小数 1 桁の m/s | — |
| 緯度・経度 | 小数 3 桁 | 未取得 |
| 最終受信 | UTC 時刻 | 有効な機体では時刻がある |
| 受信からの経過 | 秒前、分前、時間前 | 不正な時刻は — |
| 位置の取得方法 | ADS-B、ASTERIX、MLAT、FLARM など | Unknown |
| 情報源 | OpenSky または DEMO の説明 | 応答の情報源を利用 |

垂直速度が 0.5 m/s より大きい場合は上向き、-0.5 m/s より小さい場合は下向き、それ以外は水平の記号を付ける。
取得できない高度や速度を推測して補完しない。
位置がないときは位置確認ボタンを無効化する。閉じる操作で選択前の案内へ戻る。
最新データから選択した ICAO24 がなくなった場合も、選択前の案内へ戻る。
初版の画面詳細はダッシュボードの機体配列から作成し、別の詳細 API 通信は実行しない。

## 8. フライト一覧と検索

入力欄は callsign・ICAO24・登録国の部分一致に対応し、入力のたびに地図と一覧を更新する。
検索語の前後の空白を除き、大文字小文字を区別しない。
検索クリアボタンは検索語があるときだけ表示する。
「便名順」は callsign、欠損時は ICAO24 の表示名で並べる。
高度と速度は値が高い順に並べ、欠損値は並び替えの計算上 -1 として扱う。
通常の正の値は欠損値より前になるが、負の高度を持つ機体と欠損値の順位もこの扱いに従う。

一覧と地図の対象は、バックエンドが返した飛行中の機体である。地上機は含めない。
行を押す、または行内の機体名ボタンを押すと詳細が開く。
選択行を強調し、前／次ボタンで 8 件ずつ移動する。
先頭で前、最終ページで次を無効化し、表示範囲・検索結果件数・現在ページを示す。

## 9. 履歴と時刻の意味

履歴グラフは API が返した観測点を観測時刻順に線で結ぶ。
ライブとデモの履歴を混ぜず、2 点未満では観測を蓄積する案内を出す。
グラフの縦軸は現在の値の範囲に合わせた表示であり、ゼロ基準の棒グラフではない。
線の途中は補間表示であり、その時刻に実際の観測を取得したことを意味しない。
観測がない区間の正確な連続変化を保証しない。

観測時刻は提供元の観測の基準、取得時刻はサーバーの保存タイミングであり、同じ時刻とは限らない。
次回更新の秒数は、上流への次回取得を試みられる時刻までの表示である。
API へのアクセスがない場合、その時刻に必ず取得が実行されるわけではない。
画面の時刻は UTC の時分秒、履歴端点は UTC の時分を表示する。
初版は日本時間への切替や日付を伴う時刻表示を設けていない。

## 10. モード切替と狭い画面

ライブ／デモの切替時は検索語、ページ、選択機体をリセットし、並び順の選択は保持する。
別モードの古い応答が到着しても、現在のモードのデータとして表示しない。
デモバナーや取得不可の案内からも、明示的にモードを切り替えられる。

狭い画面では表をその領域内で横にスクロールできる。
ページ全体を横にはみ出させずに操作できることを、幅 390 px のブラウザーテストで確認する。
CSS の最小幅は 360 px であり、それ未満の幅への対応を保証していない。
一部のヘッダー項目は狭い画面で非表示にするが、検索・選択・モード切替は残す。
主要な操作には支援用ラベルとフォーカス表示を付ける。

受入時は地図選択、一覧選択、検索、モード切替、欠損表示、取得不可、古い観測、狭い画面を確認する。
具体的な手順は[テスト仕様](07-test-specification.md)、導入は[Windows のセットアップ](09-windows-setup.md)を参照する。
